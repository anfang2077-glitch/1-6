# Focus Rubric

Use this rubric to decide whether a trending repository should be marked as `重点关注`.

## Primary Focus Buckets

### AI 开源项目

Mark a repository when its description or README clearly centers on:

- Foundation models, inference, fine-tuning, evaluation, RAG, embeddings
- Multimodal AI such as image, video, speech, audio, OCR, vision-language systems
- Open source AI applications or AI-native tooling built around models

Common English signals:

- `ai`
- `llm`
- `model`
- `inference`
- `rag`
- `embedding`
- `diffusion`
- `vision`
- `speech`
- `multimodal`
- `dataset`

### AI 智能体及其辅助工作

Mark a repository when it helps build, orchestrate, evaluate, or operate agents:

- Agent frameworks
- Multi-agent coordination
- Tool calling, browser automation, workflow orchestration
- Agent memory, planning, evaluation, observability, guardrails

Common English signals:

- `agent`
- `multi-agent`
- `workflow`
- `tool calling`
- `automation`
- `browser use`
- `mcp`
- `orchestrator`
- `planner`
- `copilot`

### AI 软件开发/代码自动化

Mark a repository when it applies AI directly to software engineering or developer workflows:

- AI coding assistants
- Code generation, review, debugging, testing, refactoring
- IDE or CLI tooling for AI-assisted development
- Automated PR, CI, codebase search, or coding workflows

Common English signals:

- `code`
- `coding`
- `developer`
- `devtool`
- `software engineering`
- `code review`
- `debug`
- `test generation`
- `ide`
- `cli`
- `repository automation`

## Keep But Do Not Focus

Do not remove repositories when they are outside the focus buckets.
Keep them in the article and use them as supporting evidence for broader ecosystem trends.

## Tie-Break Rule

When a repository matches multiple buckets, keep all matching labels and prefer this display order:

1. `AI 软件开发/代码自动化`
2. `AI 智能体及其辅助工作`
3. `AI 开源项目`
